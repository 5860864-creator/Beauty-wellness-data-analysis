# Beauty & Wellness Data Analysis

## Project Overview
This beginner-friendly Python project explores skincare products and their customer ratings. It demonstrates how basic Python programming can help organise product data and identify simple patterns.

## Objectives
- Display skincare product information.
- Calculate average ratings for each product category.
- Identify the highest-rated product in the sample.
- Understand how Python can support basic data analysis.

## Tools Used
- Python
- Lists and dictionaries
- Loops and conditional statements
- Basic calculations

## Project Files
- skincare_analysis.py - Python program for analysing sample skincare product data.

## Methodology
The program stores sample product names, categories, prices, and ratings. It groups ratings by category, calculates the average rating for each category, and identifies the product with the highest rating.

## Important Note
The data in this project is illustrative sample data, not verified real-world customer data. The results should not be treated as actual market research.
